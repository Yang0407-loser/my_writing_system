- **重要度**：`3` 致命连续性状态；`2` 重要承接信息；`1` 辅助细节；`0` 不应交接。
- **忠实**：该句是否准确表达本小节正文已经发生或仍成立的事实。
- **类型合理**：`人物状态` / `待承接` / `新事实` / `伏笔` 的投影位置是否合理。
- **值得交接**：下一小节 Writer 是否有必要知道；不是“原文存在”就必然值得交接。
- **下游承接**：
  - `正确保持`：没有明说，但状态未被破坏；
  - `正确使用`：正文显式承接、推进或合理改变；
  - `无须体现`：辅助信息未出现，不构成问题；
  - `违反`：下一小节与该状态矛盾、重复已完成事件或错误推进；
  - `未消费/不可评`：末小节、缺少对应下游正文或无法判断。
- **结论**：`保留` / `降级辅助` / `删除噪声` / `错误`。
- 每节评完后必须检查“关键遗漏项”；没有遗漏时填写“无”，不要留空。
